# glowing-winner
職業訓練校で学習した JavaScript の授業作品です。 DOM操作、イベント処理、乱数を使った簡易バトルゲームを制作しました。

## 概要
勇者と敵キャラクターが戦うシンプルなバトルゲームです。
攻撃・回復魔法・攻撃魔法の3つの行動を選択し、敵のHPを0にすると勝利します。

## 主な機能
- ランダムダメージによる攻撃処理
- MP消費による回復魔法・攻撃魔法
- 会心の一撃（クリティカル）の発生
- HP・MPのリアルタイム更新
- DOM操作による戦闘ログ表示
- 勝敗判定と画面切り替え

## 使用技術
- HTML / CSS
- JavaScript（DOM操作・イベント処理・乱数）
